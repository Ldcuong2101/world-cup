2. Kèo chấp (Rating)

Mỗi trận có kèo chấp dạng Home : Away. Kết quả tính điểm = bàn thắng thực tế + kèo chấp.

{# Formula box #}

Công thức

Điểm sau kèo (Home) = Bàn thắng Home + Kèo Home
Điểm sau kèo (Away) = Bàn thắng Away + Kèo Away
→ Đội nào điểm cao hơn = thắng kèo
→ Nếu bằng nhau = hòa kèo (không cộng / không trừ điểm)
{# Examples #}
{# Example 1 #}

✅ Ví dụ 1 — Chọn đúng

Kèo: Pháp 0 : 1.5 Iceland
Kết quả thực: Pháp 2 – Iceland 0
Pháp: 2 + 0 = 2   |   Iceland: 0 + 1.5 = 1.5
✅ 2 > 1.5 → Pháp thắng kèo — Người chọn Pháp được điểm
{# Example 2 #}

🔄 Ví dụ 2 — Đảo chiều vì kèo

Kèo: Pháp 0 : 2.5 Iceland
Kết quả thực: Pháp 2 – Iceland 0
Pháp: 2 + 0 = 2   |   Iceland: 0 + 2.5 = 2.5
⚠️ 2 < 2.5 → Iceland thắng kèo — Người chọn Iceland được điểm dù thua thực tế!
{# Example 3 #}

➖ Ví dụ 3 — Hòa kèo

Kèo: Pháp 0 : 2 Iceland
Kết quả thực: Pháp 2 – Iceland 0
Pháp: 2 + 0 = 2   |   Iceland: 0 + 2 = 2
➖ 2 = 2 → Hòa kèo — Không cộng / không trừ điểm cho tất cả
